# Спецификация языка Renderex v0.1

Renderex — декларативный язык описания сцены: **окно + фон + объекты**.
Никакой логики: ни переменных, ни условий, ни циклов. Программа — это
список команд; результат — нативное окно с отрисованной сценой.

## Общая структура

```
window <ширина> <высота> ["заголовок"]
background <цвет>
<объект> <аргументы>
<объект> <аргументы>
...
```

- Команды разделяются **переводом строки** или **`;`**.
- `//` — комментарий до конца строки.
- Команда `window` **обязательна**, встречается ровно один раз.
- Команда `background` необязательна (по умолчанию чёрный), последняя
  выигрывает.
- Объекты рисуются **в порядке перечисления**: поздние — поверх ранних.
- Начало координат — **левый верхний угол** окна, ось Y направлена вниз,
  единицы — пиксели.
- Объекты, выходящие за края окна, обрезаются (не ошибка).
- Регистр команд и цветов не важен: `CIRCLE` = `circle` = `Circle`.

## Числа

Целые, могут быть отрицательными (для координат). Размеры окон и фигур
должны быть положительными. Максимальная сторона окна — **16384 px**.

Склейка вида `800x600` допускается после первого числа пары
(ширина×высота): `window 800x600` работает как `window 800 600`.

## Цвета

| Форма | Пример | Значение |
|---|---|---|
| `#rgb` | `#f00` | красный |
| `#rgba` | `#f008` | красный, альфа 0x88 |
| `#rrggbb` | `#ff0000` | красный |
| `#rrggbbaa` | `#ff000080` | красный, полупрозрачный |
| имя | `red`, `teal` | именованный цвет |

Именованные цвета: `black white red green lime blue yellow cyan aqua
magenta fuchsia gray grey silver maroon purple olive navy teal orange
pink brown gold violet indigo coral tomato salmon khaki turquoise
crimson beige`.

Полупрозрачные цвета смешиваются с фоном и нижележащими объектами
(альфа-смешивание).

## Команды

### Окно

```
window <ширина> <высота> ["заголовок"]     # алиас: win
```
Заголовок по умолчанию — `Renderex`.

### Фон

```
background <цвет>                           # алиас: bg
```

### Фигуры

```
square   <x> <y> <размер> <цвет>            # алиас: sq   — квадрат
rect     <x> <y> <ширина> <высота> <цвет>   # прямоугольник
circle   <x> <y> <радиус> <цвет>            # алиас: circ — круг
ellipse  <x> <y> <rx> <ry> <цвет>           # эллипс
triangle <x1> <y1> <x2> <y2> <x3> <y3> <цвет>  # алиас: tri
line     <x1> <y1> <x2> <y2> <цвет> [толщина]  # отрезок, толщина по умолчанию 1
```

`x, y` — центр круга/эллипса и левый верхний угол квадрата/прямоугольника.

### Изображения

```
image <x> <y> <ширина> <высота> "<источник>"   # алиас: img
```

Источник:

- **URL**: `https://...` — скачивается при запуске (кэшируется в памяти
  на время запуска).
- **Локальный путь**: `assets/pic.png` — относительно папки `.rx`-файла;
  абсолютный путь тоже работает.

Поддерживаются PNG, JPEG, GIF (первый кадр), WebP, BMP. Изображение
масштабируется под заданные ширину/высоту, прозрачность сохраняется.

## Полный пример

```
// demo.rx
window 800 600 "Привет, renderex!"
background #101020

circle 150 300 90 #3498db
square 300 200 130 tomato
rect 480 380 260 160 #2ecc71
triangle 150 120 260 90 210 220 gold
ellipse 550 150 120 70 #9b59b6
line 90 60 700 60 white 3
image 480 90 220 140 "https://picsum.photos/id/1080/400/250"
```

## Ошибки

Все ошибки содержат позицию `строка:колонка` и печатаются в стиле rustc:

```
error: неизвестная команда 'circl'
  --> demo.rx:2:1
    |
  2 | circl 10 10 5 red
    | ^^^^^
```

## Конвейер компиляции

```
исходник.rx
   │  lexer      (текст → токены)
   ▼
токены
   │  parser     (токены → AST)
   ▼
Scene { window, background, objects }
   │  engine     (AST → пиксели)
   ▼
фреймбуфер (u32 RGBA) ──┬─► нативное окно (winit)
                        └─► PNG-файл (--output)
```
