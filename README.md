# Renderex

**Renderex** — декларативный мини-язык для рендеринга нативных окон:
задаёшь разрешение, цвета, фигуры и изображения (в том числе по
веб-ссылке) — и получаешь окно с отрисованной сценой.

```renderex
window 800 600 "Привет, renderex!"   // разрешение и заголовок окна
background #101020                   // цвет фона

circle 150 300 90 #3498db            // круг: x, y, радиус, цвет
square 300 200 130 tomato            // квадрат
rect 480 380 260 160 #2ecc71         // прямоугольник
triangle 150 120 260 90 210 220 gold // треугольник
line 90 60 700 60 white 3            // линия с толщиной

// изображение прямо из интернета:
image 480 90 220 140 "https://picsum.photos/id/1080/400/250"
```

Язык чисто декларативный: без переменных, условий и циклов — как CSS
для окон. Спроектирован как модуль, который позже можно встроить в
другой язык программирования (см. [docs/EMBEDDING.ru.md](docs/EMBEDDING.ru.md)).

## Возможности

- 🪟 Нативное окно произвольного разрешения и заголовка
- 🎨 Цвета: HEX (`#f00`, `#ff0000`, `#ff000080`) и именованные (`red`, `teal`)
- 🔷 Фигуры: квадрат, прямоугольник, круг, эллипс, треугольник, линия
- 🖼 Изображения: по URL из интернета или из локального файла,
  с масштабированием и прозрачностью
- 🥞 Порядок отрисовки: объекты, перечисленные позже, рисуются поверх
- 🧱 Полупрозрачность: альфа-смешивание цветов
- 🖨 Headless-режим: рендер сцены в PNG без окна
- ⚡ Понятные ошибки с позицией `строка:колонка` в стиле rustc

## Установка и запуск

Нужен [Rust](https://rustup.rs) (стабильный). На Windows — ничего
дополнительно, на Linux может понадобиться `libxkbcommon` (см. ниже).

```console
$ cargo run --release -- examples/demo.rx          # показать окно
$ cargo run --release -- examples/demo.rx -o out.png  # отрисовать в PNG
```

Esc или закрытие окна завершает программу.

### Linux (WSL / сервер без дисплея)

Для окна нужны системные библиотеки winit:

```console
# Ubuntu / Debian
sudo apt install libxkbcommon-dev libwayland-dev
```

Если дисплея нет (WSL без WSLg, сервер, CI) — используйте режим PNG:
`-o file.png` работает везде.

## Язык за 60 секунд

| Команда | Назначение |
|---|---|
| `window 800 600 "Заголовок"` | окно (обязательно, один раз) |
| `background #112233` | цвет фона |
| `square x y size цвет` | квадрат |
| `rect x y w h цвет` | прямоугольник |
| `circle x y r цвет` | круг |
| `ellipse x y rx ry цвет` | эллипс |
| `triangle x1 y1 x2 y2 x3 y3 цвет` | треугольник |
| `line x1 y1 x2 y2 цвет [толщина]` | линия |
| `image x y w h "URL или путь"` | изображение |

Команды разделяются переносом строки или `;`, комментарии — `//`.
Алиасы: `win`, `bg`, `sq`, `circ`, `tri`, `img`. Размеры можно писать
склейкой: `window 800x600`.

Полная спецификация: [docs/SPEC.ru.md](docs/SPEC.ru.md).

## Проект

```
src/
  lexer.rs    — текст → токены
  parser.rs   — токены → AST (Scene)
  ast.rs      — окно, фон, объекты
  color.rs    — HEX и именованные цвета
  diag.rs     — ошибки с позицией
  engine/
    framebuffer.rs — программная отрисовка (rect, circle, line, blit…)
    headless.rs    — рендер в PNG без окна
    window.rs      — нативное окно (winit + softbuffer)
    mod.rs         — загрузка изображений, отрисовка сцены
examples/    — готовые сцены .rx
docs/        — спецификация и руководство по встраиванию
tests/       — юнит- и интеграционные тесты
```
